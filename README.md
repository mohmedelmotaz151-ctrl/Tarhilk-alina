# ترحيلك علينا

منصة عربية تربط الباحثين عن ترحيل بأصحاب السيارات الذين لديهم مقاعد متاحة.

## المزايا في النسخة الأولية
- واجهة عربية RTL متوافقة مع الجوال.
- نشر طلب ترحيل أو عرض سيارة.
- استعراض الإعلانات والبحث باسم مدينة الانطلاق أو الوجهة.
- التواصل عبر الاتصال وواتساب.
- لا تستخدم المنصة GPS أو خرائط أو تتبعاً للمواقع.

## التشغيل محلياً

```bash
npm install
npm run dev
```

ثم افتح http://localhost:3000.

## ملاحظة مهمة
هذه نسخة واجهة أولية؛ الإعلانات حالياً تجريبية ومحفوظة في حالة الصفحة فقط. قبل الإطلاق العام يجب ربط تسجيل الدخول وقاعدة بيانات دائمة (مثل Firebase)، وإضافة التحقق من أرقام الجوال، والإبلاغ والحظر ولوحة الإدارة، ومراجعة متطلبات وتصاريح نقل الركاب المعمول بها في السعودية. لا تضع بيانات Firebase السرية داخل المستودع؛ استخدم متغيرات البيئة.
